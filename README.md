# PPOIS Labs

Laboratory assignments for the **PPOIS** course at BSUIR.

## Projects

- **Englorus** — Laboratory assignment 1.
- **Polynomial** — Laboratory assignment 1.

## Build

The projects use CMake and a C++ compiler.

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
```

Run these commands from the directory containing the relevant `CMakeLists.txt`.
